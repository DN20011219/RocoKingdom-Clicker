## 新功能

### 1. PathPlanner 四策略路径扰动引擎

路径扰动引擎从双策略升级为四策略可切换架构，所有策略保证：总耗时不变、终点位移精确一致、全程使用相对量不依赖绝对坐标。

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| `straight` | 纯直线均匀插值，无任何扰动 | 调试桥接路径逻辑、隔离扰动影响 |
| `sine` | 正弦垂直扰动，`sin(πu)` 包络保证首尾为零 | 简单场景、平滑弧线 |
| `fitts` | 平滑低频正弦波 + 垂直弧线 + 过冲修正 | 日常拟人化回放（默认） |
| `neuromotor` | 间歇预测控制模型（Intermittent Predictive Control） | 高仿真拟人化 |

**neuromotor 策略**融合 2021–2025 顶会前沿研究：

- 间歇子运动链 — Do & Chang, CHI 2021 (BUMP)：离散弹道子运动序列
- 感知延迟 + 噪声重规划 — Klar et al., arXiv 2025 (Active Inference)
- Lognormal 速度脉冲 — Rudakov et al., arXiv 2025 (SSSUMO)：非对称钟形速度剖面
- 熵控相位随机 — Liu et al., arXiv 2024 (DMTG)：快=高熵，慢=低熵

**fitts 策略平滑性优化**：用 2~4 个随机频率正弦波（0.5~3.0Hz）叠加替代原独立高斯噪声，步间自然相关，模拟手臂惯性运动，平滑度提升 2.3 倍。

**随机种子唯一性保证**：三重机制（纳秒时间戳 ⊕ 64 位随机数 ⊕ 类级调用计数器 × 黄金比例常数），确保同一循环内多段调用绝不产生相同种子。

### 2. 段锚点区间保护模式

新增「段锚点」模式（`anchor_mode: segment`），与原有「点锚点」模式并存：

- **录制**：长按锚点键（如 F12）划定操作保护区间，按下时插入 `segment_start` 事件，松开时插入 `segment_end` 事件
- **回放**：
  - 段内所有操作（move/click/key）100% 原样重放（零偏差、时间精确）
  - 相邻保护段之间的桥接路径复用 PathPlanner 扰动算法生成拟人化移动
- **模式切换**：GUI 下拉框选择「点锚点」或「段锚点」，配置持久化
- **向后兼容**：旧脚本（无段事件）自动按点锚点模式处理；回放引擎通过检测 `segment_start`/`segment_end` 事件自动识别模式
- **安全关闭**：录制停止时若段未关闭（用户按住锚点键时按了停止键），自动补 `segment_end`

### 3. 路径扰动算法 GUI 配置面板

- **策略下拉框**：右栏新增路径扰动配置卡片，可通过 Combobox 切换四种策略
- **参数实时调节**：每种策略的关键参数（振幅、频率、过冲概率、neuromotor 各系数等）均可在界面中调整
- **配置持久化**：新增 `data/clicker_configs/path_planner.json`，`ConfigManager.load_path_planner()` / `save_path_planner()` 负责读写
- **运行时同步**：保存配置后立即同步到 `PlaybackEngine.path_planner_params`，下轮回放即生效
- **深色主题适配**：Combobox 组件完整适配深色主题（fieldbackground / foreground / arrowcolor / bordercolor 状态映射）

### 4. 锚点热键可配置化

- 锚点热键从硬编码 `0x58`（F12）改为通过 `hotkeys.json` 配置，用户可改为 F1-F12 任意键
- `hotkeys.json` 新增 `"mark_anchor": "F12"` 字段
- 快捷键面板新增「标记锚点（录制中）」配置行和彩色按键徽章
- `InputRecorder.set_hotkeys()` 新增 `anchor` 参数，4 键（start/stop/cancel/anchor）互斥检查

### 5. 驱动硬件时间戳修复

- **问题**：`interception_wait` 阻塞 → 批量取事件 → Python 循环用 `perf_counter()` 打时间戳，batch 内事件时间戳几乎相同，丢失真实间隔
- **修复**：使用 `stroke.information` 字段（Windows 硬件级时间戳，毫秒，等同 `GetTickCount()`）作为事件时间源
- **键盘偏移修正**：`MouseStroke.information` 在 offset 16，`KeyStroke.information` 在 offset 4，键盘事件必须用 `ctypes.memmove` 从正确偏移读取
- **Fallback**：`information == 0` 时（虚拟化环境等罕见情况）回退到 `perf_counter()`

## 重要前置要求

> **Windows「增强指针精度」必须关闭**
>
> Windows 设置 → 蓝牙和其他设备 → 鼠标 → 增强指针精度 → **关闭**
>
> 该选项开启时 Windows 会对鼠标增量施加非线性加速，导致路径扰动策略回放后的实际屏幕位移与原始录制不一致（锚点位置偏移）。关闭后 Interception 注入的相对增量将 1:1 对应屏幕像素移动，锚点精度才有保障。

## 快速验证步骤

1. **路径扰动策略切换**：
   - 打开 GUI → 右栏路径扰动配置 → 切换策略为 `neuromotor` → 保存
   - 录制一段鼠标移动脚本（按 F12 标记锚点），回放多次确认路径各异、锚点位置精确

2. **段锚点模式**：
   - GUI 切换锚点模式为「段锚点」
   - 录制时长按 F12 划定保护区间（段内执行精确操作），松开后继续移动
   - 回放确认：段内操作完全一致，段间移动路径有拟人化扰动

3. **硬件时间戳**：
   - 快速移动鼠标录制，检查 JSON 中相邻 move 事件的 `t` 差值有合理的毫秒级间隔
   - 回放速度与录制时一致（不会加速）

4. **前置要求验证**：
   - 确认 Windows「增强指针精度」已关闭
   - 使用 `straight` 策略回放，锚点位置应精确无偏移

## 调试与注意事项

- PathPlanner 默认使用 `fitts` 策略，可通过 GUI 配置面板或代码中设置 `PlaybackEngine.path_strategy` 切换
- `straight` 策略仅用于调试，在 Windows 鼠标加速开启时会产生定位偏差（非线性畸变）
- 段锚点模式下录制开始不自动注入起始锚点（与点锚点模式不同）
- 硬件时间戳 `information` 字段为 32 位无符号整数，约 49.7 天回绕一次，正常录制不会触发
- 旧录制文件（无锚点/段数据）回放时行为不变，完全向后兼容
- neuromotor 策略参数说明：
  - `nm_lognormal_sigma`：Lognormal 速度剖面宽度（0.4~0.9）
  - `nm_perception_noise`：感知噪声系数（占距离比例）
  - `nm_entropy_alpha`：熵控强度（0=无，1=最强）
  - `nm_lateral_drift`：横向漂移幅度（占距离比例）
  - `nm_max_corrections`：最大修正子运动次数
