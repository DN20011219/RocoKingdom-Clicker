## 新功能

### 1. 窗口区域连点（第四栏）

针对「在一个窗口范围内随机点击」的需求：给定一个屏幕矩形区域，鼠标在区域内随机取点 → 在该点连点 N 次（带完整抖动）→ 用拟人化轨迹移动到下一个随机点 → 循环。

- **区域录制两种方式**：`📐 拖拽圈选` 铺满整个虚拟屏（支持多显示器负坐标），拖框即得矩形；`🪟 拾取窗口` 倒计时 3 秒后自动取光标下窗口的**可视边界**（DWM 扩展边界，不含阴影与不可见边框）。`Esc` / 右键取消。
- **纯相对位移注入**：全程只发相对 `move` stroke，不使用绝对坐标。因此天然支持多显示器（含负坐标）与光标被游戏锁定的场景，与项目「锚点零偏差」的设计一致。
- **首点进入不瞬移**：启动时先读当前光标位置，用与后续换点完全相同的相对轨迹移动到区域内第一个随机点。
- **落点抖动不游走**：单次点击的抖动通过「微移 → 按下 → 抬起 → 反向补偿」实现，多次点击的落点彼此独立随机，但基准点不会随机漂移。
- **漂移校正**：`correct_drift_px > 0` 时每次换点后比对实际光标位置，误差超阈值就补发一个相对 `move`；设 `0` 关闭。长跑时手动把鼠标拖离区域也能拉回来。
- **轨迹复用 PathPlanner**：四种策略（`straight` / `sine` / `fitts` / `neuromotor`）均可用于换点移动；`path_strategy="global"` 时读第三栏保存的配置。
- **可中断**：换点、点击间隔、按住时长、移动过程全程响应 `F2` 暂停/继续与停止按钮。
- **运行时显示区域边框**：勾上「🔲 运行时显示区域边框」后，连点期间区域四周常驻一圈青色边框，方便确认鼠标确实落在预期范围内。边框做到**完全点击穿透**：画在区域外侧 + Tk `-transparentcolor` 颜色键 + `WS_EX_TRANSPARENT` 三层保障叠加，注入的点击照常打到游戏。三层全失效时抛 `RegionOutlineUnavailable`、宁可不显示也不放一个会吞点击的窗口上去（会 toast 提示一次）。生命周期挂在已有的 500ms 状态轮询上，区域未变时不重建（不闪）、停止即销毁（不留残窗）。开关为纯显示偏好，不落盘，默认打开。
- **不受 `move_mouse` 开关影响**：区域连点以移动为核心，全局「启动时移动鼠标」开关关闭时功能照常工作，启动会额外 toast 说明，避免误判。
- **区域预设持久化**：`data/clicker_configs/region_presets.json`，面板可存/删/选；手写脚本可用 `"region_preset": "预设名"` 引用。
- **新热键 `record_region`（默认 F6）**，可在热键面板改。
- 新动作类型 `region_click` 也可写在脚本里，支持内联 `region` / 扁平字段 / `region_preset` 三种写法，字段说明见 `data/action_scripts/SCRIPT_RULES.md` 第 7 节。

### 2. MIDI 自动演奏（第五栏）

给定一套「音 → 键盘按键」的绑定，把任意 MIDI 曲谱按原速自动弹出来。

- **纯标准库实现**：MIDI 解析自己写（`MidiScore.py`），不引入 mido / python-midi。支持 format 0/1/2、running status、变速表（`Set Tempo` 分段线性换算，变速曲谱时间轴准确）、SMPTE 时基、sysex 跳过、`note on(velocity=0)` 当 note off、同音高叠置的 FIFO 配对、缺少 note off 的悬挂音符补到轨道末尾（记 warning，不静默丢音）。
- **能不能演奏，先说清楚**：曲谱里出现的**每个**音都必须在键位表里有按键才允许开演。缺音时逐条列出「哪个音、出现几次、首次在第几秒、最接近的已绑定音是哪个、差几个半音」，`▶` 按钮变成 `⚠ 无法演奏 · 查看原因`，点下去弹出完整清单 —— 不会静默跳过几个音就开演。
- **移调**：音域不合时可整体平移；勾上「自动移调」后，若原调演奏不了，会在 ±24 半音内自动挑一个**能覆盖全部音符且移调量最小**的方案。半音阶这类谱子没有任何移调量能救，面板会直接说明。
- **键位可改**：默认是《洛克王国：世界》手碟九键（`A2→B`、`E3→F`、`F3→G`、`G3→H`、`A3→J`、`B3→K`、`C4→T`、`D4→Y`、`E4→U`，中央 C = 60 = C4）。`✏ 编辑键位` 可改按键、删绑定、按音名（`C#4` / `Db4`）或 MIDI 音高数字新增；保存时校验按键合法性与一键多音冲突。
- **同键重叠自动重触发**：一个键被按住时再按不会发声，所以同键音符重叠时引擎会提前 12ms 抬手再按下，保证每个音都真的触发一次。
- **时序稳定**：按绝对时间轴调度（不是累加 sleep，误差不会随音符数漂移），演奏期间把系统时钟精度提到 1ms（`winmm.timeBeginPeriod`），结束后还原。速度倍率 10%~400%，支持循环与轮间隔。
- **绝不留卡键**：播完 / 暂停 / 停止 / 异常任何退出路径都抬起所有按住的键。
- **按键注入走 Interception 内核驱动**（与脚本系统同一条通道），失败才回退 `keybd_event`；`VK_TO_SCANCODE` 已补齐主键盘区标点与小键盘运算符，绑到这些键也能走内核注入。
- **互斥与热键**：演奏与脚本、回放、录制互斥；演奏期间只认 `F2` 暂停/继续，其余热键被忽略 —— 注入的按键同样会被键盘钩子看到，否则绑到 F 功能键的音符会误触发录制或圈选。倒计时阶段按 `F2` 直接取消。
- **曲谱库**：把 `.mid` / `.midi` 放进 `data/music/`，或点 `📂 导入 MIDI`（复制进来，重名自动加序号）。程序启动即自动列出并选中第一首、立刻出检查结论。参数持久化在 `data/clicker_configs/music_player.json`。

曲谱推荐来源：**RocoMusic（洛克乐谱）** <https://rocomusic.cn/> —— 面向《洛克王国》玩家的非官方 MIDI 曲谱社区，另有「求谱广场」与「手碟转谱」。本项目默认键位就是该游戏的手碟九键，那边的谱子基本可以直接演奏。发布包附带 6 首来自该站的示例曲谱，版权归原作者与转录者所有，清单见 `data/music/README.md`。

### 3. 脚本市场（V1 静态市场）

中栏脚本列表新增 `🛒 脚本市场` 入口，可浏览、下载、导入市场里的脚本，也能把本地脚本打包导出上传。

- **零第三方依赖**：索引拉取与文件下载走 `urllib`，只用标准库。
- **脚本包格式 v2**（向后兼容 v1）：在动作之外携带 `market`（id/title/author/version/game/tags/description）与 `environment`（分辨率、DPI 缩放、指针速度、鼠标加速状态）元数据；`click` / `move` 动作可带 `x_norm` / `y_norm` 归一化坐标。
- **分辨率自动换算**：导入时按本机分辨率把归一化坐标换算成像素坐标；也支持运行时动态换算模式。没有归一化坐标的动作保持原像素值不变，v1 旧脚本原样可用。
- **环境兼容性比对**：下载前比对脚本声明环境与本机环境，给出 info / warn 级提示 —— 分辨率不一致（含宽高比不同时的额外警告）、指针速度不一致、本机未关闭「提高指针精确度」等。
- **导入端安全校验**：动作类型白名单、每种动作的字段白名单、`x_norm`/`y_norm` 取值范围、`vk_code` 范围、嵌套深度上限 8、动作总数上限 10000、单包 512KB 上限、非法 JSON 拒绝，以及**危险组合键黑名单**（Ctrl+Alt+Del、Win+L、Win+D、Win+R、Win+Tab 等）。导入与上传两端复用同一套校验。
- **已安装状态与更新检查**：记录已导入脚本的 id 与版本，比对市场版本后给出 `not_installed` / `up_to_date` / `update_available`。
- **上传流程（V1）**：`⬆ 上传我的脚本` 生成上传包 JSON，随后到市场仓库提交 PR，把文件放进 `scripts/` 并在 `index.json` 里添加条目。
- **需要自己配置索引地址**：`index_url` / `repo_url` 默认为空，在 `⚙ 市场设置` 里填写。未配置时列表为空，不会报错。

### 4. 驱动一键安装 + 提权方式改造

- **程序内一键装驱动**：检测到驱动没装好时弹框询问，点「是」后可能弹一次 UAC → 静默调用官方 `install-interception.exe /install` → 装完再问是否立即重启（选「是」走 `shutdown /r /t 15`，文案里直接告知可用 `shutdown /a` 取消）。全程不需要打开终端、不需要敲命令。详见 `docs/DRIVER_INSTALLATION.md`。
- **提权方式：`run_clicker.vbs` → exe 内嵌清单**。微软已把 VBScript 列为弃用功能，在 Windows 11 24H2/25H2 上它变成「按需功能」并逐步默认关闭，双击 `.vbs` 可能直接没反应。改为 PyInstaller `--uac-admin` 把 `requireAdministrator` 写进 exe 清单，**双击 exe 就弹 UAC**，`run_clicker.vbs` 已删除。提权由系统 loader 在进程创建前完成，比 `ShellExecute("runas")` 更硬，也不会出现「启动了但没权限」的半死状态。
- **可靠的安装痕迹检测**：Interception 以键盘/鼠标**类过滤驱动**形式安装，服务名就叫 `keyboard` / `mouse`，并没有名为 `interception` 的服务，所以 `sc query interception` 永远返回 1060（旧启动器正是踩了这个假阴性）。改查三个信号（读 HKLM，不需要管理员权限）：类键 `UpperFilters` 是否含 `mouse`/`keyboard`、服务键是否存在、`%SystemRoot%\System32\drivers\mouse.sys` 是否落地。
- **区分「未安装」与「装了没重启」**：未安装 → 默认焦点在「是」的询问框；已安装但仍不可用 → 先说明「最常见原因是还没重启」，默认焦点改到「否」，避免无意义的重装。重启对话框默认选「否」（误触回车就会重启电脑，这个默认值必须保守）。
- **失败原因分类**：新增 `dll_missing` 与 `driver_install_hint` 两个标志。DLL 缺失属打包/解压不完整，**不再引导装驱动**（重装驱动修不好），直接叫用户重新下载完整解压；只有创建上下文失败才走一键安装；「没有发现任何鼠标设备」两者都不推，只给具体原因。三条路径由 `Clicker._report_driver_not_ready()` 统一分发，不再各自拼提示文案。
- **新入口**：`install_driver.bat`（双击即可，只是启动器，弹框与程序内完全一致）、`RocoKingdom_Clicker.exe --install-driver` / `--uninstall-driver`、`python DriverInstaller.py --status|--install|--uninstall`（`--status` 只读不改系统，方便截图反馈）。
- **一个会话只主动引导一次**：`_show_driver_warning()` 会被开始点击 / 录制 / 回放 / 跑脚本四条路径反复调用，加了门闩，不会每按一次热键就来一轮安装向导。

### 5. CI 自动打包

新增 GitHub Actions 工作流（`windows-latest` + Python 3.10 + PyInstaller，调用 `build_release.bat`）：push 到 `main` 或手动触发时上传构建 Artifact；推送 `v*` 标签时额外创建 GitHub Release 并附上 `RocoKingdom_Clicker.zip`。

> 注意 CI 构建的包**不含 `data/music/*.mid`**：曲谱不入 Git，而 CI 从干净的仓库检出。只有在本机跑 `build_release.bat` 才会把本地曲谱一起打进去。

| 9 | **启动器若干问题** | `run_clicker.bat` 缺 `chcp 65001` 导致中文提示在 GBK 控制台全是乱码（已补）；检测对象由 `where python` 改为 `where pythonw`，与实际启动对象一致；`.vbs` 的系统 Python 回退分支加错误处理，救活原本永不触发的「启动失败」提示 |
| 10 | **`DriverInstaller.main()` 在发布包里抛异常** | 发布包 exe 是 `--windowed`，`sys.stdout` 为 `None`，原来的 `print()` 直接崩。拆成 `_progress()`（过程信息，仅有控制台时打印，**绝不弹框**，否则会在安装开始前就阻塞）与 `_notify()`（结果信息，无控制台时弹消息框）两个通道 |

### 清理

- **删除与 `F6` 完全等价的重复按钮**：三个区域捕获入口统一后，「🎙 录制区域」和「📐 拖拽圈选」变成完全等价的两个按钮（都投递 `drag`、都调 `select_by_drag`），只差一跳队列。删掉前者，`_rc_record_btn` 改指向拖拽圈选按钮，热键刷新逻辑把标签写成「📐 拖拽圈选 (F6)」，`F6` 的可见对应物没有丢。顺带消除「录制区域」被误读成"录制区域内的操作"的问题 —— 真正的录制是 `F7`。

## 升级注意事项

1. **主窗口变宽了**。最小尺寸 1720×900 → **2460×900**，启动宽度 1800 → **2540**（五栏布局在 2560×1600 上放得下）。第四、五栏都放在可滚动的 Canvas 容器里，小屏不会被完全遮挡，但可用面积会明显变窄。
2. **`run_clicker.vbs` 没了**。发布包用户直接双击 `RocoKingdom_Clicker.exe`（自带 UAC 提权）；源码用户走 `run_clicker.bat`。
3. **装完驱动必须重启**，否则仍会报「驱动未就绪」。这是本版本最常见的 support 项。
4. **`sc query interception` 查不到驱动是正常的**，不代表没装上。用 `python DriverInstaller.py --status` 看五项注册表痕迹。
5. **拉取本版本后 `data/clicker.log` 会从工作区消失**。这是取消跟踪的正常表现（Git 视之为一次文件删除），程序下次运行会自动重建。
6. **Windows「增强指针精度」必须关闭**（v1.6 已有此要求，区域连点同样依赖）。开启时 Windows 会对鼠标增量施加非线性加速，导致相对注入的实际位移与预期不一致，锚点精度与漂移校正都会失准。
7. **脚本市场默认没有索引地址**，需要在 `⚙ 市场设置` 里自己填 `index_url`，否则列表为空。
8. **`region_click.json` / `region_presets.json` / `music_player.json` 是运行期产物**，已加入 `.gitignore`，不会进版本库；但注意它们位于 `data/clicker_configs/`，而该目录已被排除在发布包之外，所以**发布包不会覆盖你现有的配置**。
9. **`.bat` 文件不要加中文**（维护者注意）。详见 `docs/DRIVER_INSTALLATION.md` 附录与 `README.md`「打包与发布」。

## 下载与安装

1. 下载 `RocoKingdom_Clicker.zip` 并**完整解压**到同一目录（不要在压缩包内直接双击运行，否则会报「找不到 interception.dll」—— 那是解压不完整，不是驱动问题，重装驱动修不好）。
2. 双击 `RocoKingdom_Clicker.exe` → 弹 UAC 点「是」。
3. 若提示需要驱动 → 点「是」自动安装 → 装完**重启电脑**。
4. 关闭 Windows「增强指针精度」。

驱动安装的三种方式与排查步骤见包内 `docs/DRIVER_INSTALLATION.md`。
